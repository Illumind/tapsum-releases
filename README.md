# Tapsum

<img src="logo.svg" width="96" alt="Tapsum">

**Приклав — порахував.** Облік витрат для Samsung / Android: автоматично записує покупки, оплачені
телефоном, Galaxy Watch або карткою, розкладає їх за категоріями й стежить за лімітами.

- 📦 **Завантажити:** [остання версія](https://github.com/Illumind/tapsum-releases/releases/latest) → файл `Tapsum-*.apk`
- 🔒 **Політика конфіденційності:** [privacy-policy.md](privacy-policy.md) (UA / EN / PL)
- 🐞 Питання й пропозиції: розділ Issues цього репозиторію

Цей репозиторій містить лише готові збірки та публічні документи; вихідний код зберігається окремо.
